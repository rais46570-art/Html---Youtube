# Html---Youtube

I learned HTML and CSS using a YouTube video which focused on recreating the YouTube home page.

Simple static project containing an HTML page, styles, and assets.

How to use
- Open `youtube.html` in your browser.

To publish to GitHub
1. Initialize and commit locally (already done).
2. Create a repository on GitHub and add it as `origin`.
3. Push with `git push -u origin main`.
